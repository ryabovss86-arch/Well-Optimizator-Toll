# Well-Optimizator-Toll
Вики-документация: Инженерный оптимизатор дебита скважины («Оптимизатор скважины Pro»)
«Оптимизатор скважины Pro» — это интерактивное веб-приложение на базе Streamlit, предназначенное для нефтегазовых инженеров и экономистов. На основе полиномиального тренда обводненности и заданных технологических параметров алгоритм рассчитывает величину оптимальной депрессии на пласт для максимизации суточной прибыли (EBITDA), а также вычисляет срок окупаемости инвестиций в ГТМ или ремонт скважины.
Назначение и возможности
•	Поиск оптимума: Автоматический расчет технологического режима (депрессия, дебит жидкости и нефти), при котором достигается максимальный финансовый результат.
•	Гибкая экономическая модель: Учет стоимости чистой нефти, затрат на подъем жидкости, утилизацию попутно-добываемой воды и постоянных ОПЕКС.
•	Интерактивный ввод данных: Изменение промысловых замеров (депрессия vs обводненность) в реальном времени прямо через интерфейс.
•	Визуализация: Интерактивные графики Plotly для анализа экономического купола (EBITDA от дебита) и тренда обводнения.
Математическая и экономическая модель
1. Гидродинамика
Дебит жидкости (Q_liq, м³/сут): Вычисляется по линейному закону фильтрации через коэффициент продуктивности (PI):
Q_liq = PI * ΔP
Где ΔP — депрессия в атм.
2. Моделирование обводненности
Приложение аппроксимирует введенные замеры методом наименьших квадратов (np.polyfit) с помощью полинома 2-й степени (параболический тренд):
WC(ΔP) = a * ΔP^2 + b * ΔP + c
Полученное значение обводненности программно ограничивается диапазоном от 0% до 100%.
3. Экономический расчет (за сутки)
• Дебит нефти в тоннах (Q_oil, т/сут): Q_oil = Q_liq * (1 - WC) * ρ_oil (где ρ_oil — плотность нефти, т/м³).
• Выручка (Revenue, руб/сут): Revenue = Q_oil * Price_oil
• Переменные затраты (OPEX_var, руб/сут): OPEX_var = (Q_liq * Cost_lifting) + (Q_wat * Cost_water)
• Суточный EBITDA (руб/сут): EBITDA = Revenue - (OPEX_var + OPEX_fixed)
• Срок окупаемости (сут): Payback = CAPEX / EBITDA
Инструкция по запуску (в Google Colab / Jupyter)
Скрипт полностью автономен и настроен на запуск внутри сред типа Google Colab с пробросом локального端口 в интернет через сервис Serveo.
1.	Шаг 1: Скопируйте и запустите код в ячейке Google Colab.
2.	Шаг 2: В самом низу вывода ячейки появится команда ssh. Сервер Serveo сгенерирует для вас публичную ссылку (например, https://xyz.serveo.net). Кликните по ней.
Руководство пользователя
1. Настройка параметров (Боковая панель)
•	• Технологические параметры: укажите PI скважины и плотность нефти.
•	• Экономика: введите стоимость ГТМ (CAPEX), цену тонны нефти и удельные затраты.
•	• Таблица замеров: интерактивный редактор депрессии и обводненности (минимум 3 точки).
2. Анализ результатов (Основной экран)
•	• Информационные карточки (Metrics): выводят расчетное значение оптимальной депрессии, дебит нефти, прибыль и период окупаемости.
•	• Графики: визуализация кривой EBITDA и качества моделирования тренда обводнения по реальным точкам.
Возможные ошибки и их решение
1. «Ошибка: введите минимум 3 точки замеров»
Решение: Добавьте строки в таблицу на боковой панели, чтобы восстановить матрицу для построения тренда.
2. Срок окупаемости: «Не окупается»
Решение: Проверьте экономические параметры. Возможно, затраты на утилизацию воды превышают потенциальную выручку.
