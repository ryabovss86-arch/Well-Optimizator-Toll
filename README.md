# Well-Optimizator-Toll
Well Optimizer Pro 📊 optimizes well operating drawdown pressure to maximize daily profit (EBITDA) and calculate GTM/workover payback. Features: • Optimum Search: Finds peak EBITDA vs fluid rate. • Water-Cut Fit: Models quadratic trends from 3+ test points. • Live Visuals: Interactive Plotly curves. • Word Export: Built-in wiki with .docx download.
